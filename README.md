# Perú Verde (Streamlit)
Enciclopedia ambiental del Perú. Datos en `data.json` (agrega objetos a `items`).
Local: `pip install -r requirements.txt && streamlit run app.py`
Nube: sube a GitHub y despliega en https://share.streamlit.io (archivo principal: app.py).
Datos no confirmados figuran como "Por confirmar"; verifica en fuentes oficiales.
